# 🎬 shorts-autopilot — 원본 하나로 쇼츠 완성본 & 썸네일까지

## 📌 역할
`shorts-allinone` 은 EDL + SRT 를 내주고 **사람이 리졸브를 열어야** 했다.
이 스킬은 **완성본 MP4 + 듀얼 썸네일(유튜브 9:16 + 인스타 4:5 커버)** 을 낸다. 편집 프로그램을 열 일이 없다.

원본 16:9 4K → 전사 → **내용 재구성(OREO)** → 무음 제거 → **컷 인지형 등속 인물 추적 9:16** →
영/한 자막 하드번인 + **하이라이트 줌인/초미세 버블팝 SFX** → **포토제닉 프레임 선별 & 2단 훅 썸네일** →
완성본 소리를 다시 받아적어 대본과 대조 검증 → 결과 폴더 열기.

## 🛠️ 호출 트리거
*   *"쇼츠 자동으로 만들어"*, *"원본에서 쇼츠까지 한 번에"*, *"편집 없이 쇼츠"*
*   *"3안 뽑아서 영상까지 뽑아줘"*

## 🔄 워크플로우

### 1단계 — 전사 (있으면 재사용)
긴 설교는 한 번만 전사한다. 이미 `{폴더}/{이름}.json` 이 있으면 그걸 쓴다.

### 2단계 — 후보 훑기 (직접 한다)
전사문을 3등분해 각 덩이에서 후보를 5개씩 뽑는다. **전사문 전체를 통째로 읽지 않는다** —
`sed -n` 으로 한 덩이씩 잘라 보고, 뽑은 후보만 메모에 남긴 뒤 다음 덩이로 넘어간다.
> ★**타임코드를 눈대중으로 적지 마라.** 2026-09-02 실측에서 타임코드가 통째로
> 750초 밀린 적이 있다. 후보를 확정하기 전에 **반드시 `grep` 으로 그 대사가 정말
> 그 시각에 있는지 확인**한다.

### 3단계 — OREO 로 재구성해 A/B/C 3안 설계 ★핵심
원본 순서대로 자르지 않는다. **결론을 맨 앞으로 끌어와** 재배열한다.

```
O 결론/훅   가장 세게 찌르는 한 문장 (또는 강한 질문)
R 이유      왜 그런가
E 예화      구체적 장면·인물·대사
O 재강조    펀치라인으로 마무리
```
*   구간은 **시간상 떨어져 있어도 되고 순서를 바꿔도 된다.** 이게 이 스킬의 값이다.
*   컷 경계는 `scripts/shorts_v2/` 옆에 두는 단어 타임스탬프 조회로 **단어 단위**로 잡는다
    (전사 JSON 의 `tokens[].offsets`). 문장 중간에서 자르지 않는다.
*   구간 합 55~70초를 노린다. 무음 제거로 10~30% 줄어든다(이득 없는 컷을 안 만들어서 편차가 크다).
*   플랜 JSON:
```json
{"id":"A","title":"제목","slug":"파일명_슬러그",
 "segments":[[1508.35,1520.60],[1393.45,1408.90]],
 "script":"완성본에서 실제로 들릴 한국어 대본 전문"}
```

### 4단계 — stage a (컷 → 무음 제거 → 추적)
```bash
{venv} scripts/shorts_v2/run_pipeline.py --src "{원본}" --plan plan_A.json \
       --outdir "{결과폴더}" --stage a
```
→ `{slug}_master.mov`(16:9 클린), `{slug}_master.words.json`(글자별 타임스탬프),
  `{slug}_track.json`(크롭 궤적) 생성. 마스터 길이를 출력한다.

**여기서 확인할 것**
*   `검출률` 이 95% 미만이면 크롭이 흔들린다 — `--sample-fps` 를 올리거나 구간을 바꾼다.
*   `⚠ 크롭이 한 번에 NNpx 튄다` 경고가 뜨면 그 구간을 확인한다.
*   무음 제거 후 마스터를 **다시 전사해 문장이 안 잘렸는지 눈으로 본다.**
*   `이득 0.40s 미만이라 컷하지 않음` / `조각이 1.20s 미만이라 취소한 컷` 로그를 본다.
    최종 컷 개수가 길이(초) 대비 **1/4 을 넘으면** 너무 잘게 썰린 것이다 — `--min-keep` 를 올린다.

### 5단계 — 자막 블록 설계 + 영문 번역
`{slug}_master.words.json` 의 글자 스트림을 보고 10~16자 블록으로 나눈다.
```json
[{"ko":"화면에 띄울 한국어","stt":"whisper 가 들은 그대로","en":"English line","hl":true}]
```
*   `stt` 는 **STT 오인식을 교정해 표시할 때만** 넣는다. 정렬은 `stt` 길이로 한다.
*   `hl:true` 는 클라이맥스 강조(골드 `&H00E5FF&` + 112% 확대). 한 쇼츠에 5~8개만.
*   **반드시 기계 검증한다:**
```bash
python3 scripts/shorts_v2/check_chunks.py --words {slug}_master.words.json --chunks chunks_A.json
```
    `✅ 일치` 가 안 뜨면 자막이 밀린다. 뜰 때까지 고친다.
*   영문 번역은 직접 한다(한 줄 42자 이내).
    > ★**원문이 밝히지 않은 성별을 영어로 만들지 마라.** 한국어에 없는 he/she 를
    > 지어내기 쉽다. 사람이면 they 로 쓴다.

### 6단계 — stage b (자막 + 렌더 + 검증)
```bash
{venv} scripts/shorts_v2/run_pipeline.py --src "{원본}" --plan plan_A.json \
       --outdir "{결과폴더}" --stage b --chunks "{결과폴더}/_work/chunks_A.json"
```
→ `{결과폴더}/{slug}.mp4` (1080x1920) + `{slug}_verify.md`

### 8단계 — 썸네일 & 2단 훅(Hook) 타이틀 자동 생성 및 영상 인트로 결합
```bash
python3 scripts/shorts_v2/generate_thumbnail.py \
  --mode both \
  --frame "{선정된_프레임_경로}.jpg" \
  --badge "하올람 말씀 인사이트" \
  --l1 "엄마한테만 최선을 다해" \
  --l2 "반항하는 진짜 이유" \
  --sub "밖에서는 멀쩡한 아이가 왜 집에서만 이럴까?" \
  --out-yt "{결과폴더}/{slug}_thumb_youtube.jpg" \
  --out-insta "{결과폴더}/{slug}_thumb_instagram.jpg" \
  --out-guide "{결과폴더}/{slug}_thumb_instagram_guide.jpg" \
  --video "{결과폴더}/{slug}.mp4"
```
→ `{slug}_thumb_youtube.jpg` (1080x1920 유튜브 쇼츠용, **A안: 뱃지 Y=270, L1 Y=365, L2 Y=475, Sub Y=605**)
→ `{slug}_thumb_instagram.jpg` (1080x1350 인스타그램 피드/릴스 업로드용 클린본)
→ `{slug}_thumb_instagram_guide.jpg` (1080x1350 노란 안전영역 가이드라인 검토용)
→ `{slug}.mp4` (**시네마틱 앞뒤 페이드 & 썸네일 인트로 결합 완료**: 
    - **앞 (Intro)**: 0.7s 완전무음 썸네일 정지 → 0.25s 블랙 페이드아웃 → 0.25s 본영상 페이드인 + 80ms 오디오 페이드인.
    - **뒤 (Outro)**: 영상 종료 0.40초 전부터 본영상 블랙 페이드아웃 + 오디오 페이드아웃으로 부드러운 암전 종결.
    - 원본 무수정 영상은 `{slug}_raw.mp4`로 자동 백업 보존)

> ★**A안 인스타그램 안전영역 & 앞뒤 페이드 표준 (2026-09-04 실측 확정)**:
> - **앞뒤 페이드**: 첫머리 0.7초 정지 썸네일로 플랫폼 0초 첫 프레임 썸네일 100% 보존 후 부드럽게 본영상 진입, 끝머리 0.4초 블랙/오디오 페이드아웃으로 틱 노이즈 및 급작스러운 컷 종료 방지.
> - 인스타 프로필 3:4 릴스 탭(Y=240~1680)에서 상단 뱃지가 잘리지 않고, 1행 타이틀이 우측 상단 릴스 아이콘(▶) 아래로 완벽히 내려와 수납됨.
> - 설교자 손 제스처(Y=820)와 서브티저(Y=605) 사이에 160px 이상의 쾌적한 안전 여백 확보.
> - 플랫폼 자동 업로드 시 0초 첫 프레임 썸네일을 100% 무손실로 캡처 가능.

### 9단계 — ★끝까지 검토한 뒤에만 오너에게 가져간다
1.  **유사도 95% 이상**인지. 미만이면 리포트의 차이 구간을 본다.
2.  **차이 구간을 하나씩 판정한다.** 조사·군말(요/이제/막/뭐) 누락은 STT 한계라 넘어가도
    되지만, **뜻이 달라지는 차이는 격리 오디오로 재전사해 진짜 뭐라고 말하는지 확인한다.**
    ```bash
    ffmpeg -ss {a} -to {b} -i {master} -vn -ac 1 -ar 16000 q.wav
    whisper-cli -m large-v3 -f q.wav -l ko -np -nt --beam-size 8
    ```
    좁은 창과 넓은 창 둘 다 돌려 일치하는 쪽을 택한다. (2026-09-02 실측: 이렇게 해서
    "하나님 없는 거 아니에요" 가 실은 `'하나님 없는 거 아니야?'가 아니라` 인 걸 잡았다.)
3.  **프레임을 실제로 본다.** 4~6개 시점을 뽑아 인물이 화면 안에 있는지, 자막이
    노트북·손에 안 가리는지 확인한다.
4.  **썸네일 가이드라인 및 인트로를 확인한다.** 인스타 3:4 릴스 탭 및 4:5 피드에서
    제목과 얼굴이 잘리지 않고, 영상 시작 시 0.7초간 무음 썸네일 노출 후 블랙 페이드 전환이 매끄러운지 검증한다.
5.  통과하면 결과 폴더를 연다: `open "{결과폴더}"`

## 🖼️ 썸네일 & 인스타그램 안전영역 규격
*   **유튜브 쇼츠용 (1080×1920, 9:16)**:
    *   상단 딤 그라디언트 + 상단 뱃지 (`하올람 말씀 인사이트`)
    *   메인 타이틀 1행 (`SB 어그로 B`, 화이트, 82pt)
    *   메인 타이틀 2행 (`SB 어그로 B`, 골드 `#FFE843`, 96pt)
    *   서브 티저 박스 (Apple SD Gothic Neo, 38pt, 반투명 블랙 라운드 박스)
*   **인스타그램 릴스/피드 커버용 (1080×1350, 4:5)**:
    *   캔바 사진 프레임: `x=[105, 975], y=[42, 1200]` (870×1158 카드 형태)
    *   **노란 가이드라인 (안전영역)**: `x=[161, 921], y=[164, 1145]` (760×981)
    *   인스타 홈 피드(4:5) 및 프로필 그리드(1:1) 크롭 시 글자가 잘려나가지 않도록 **모든 타이포그래피를 노란 가이드 상단에 수납**
    *   출력: 실제 업로드용 **클린본 (`_thumb_instagram.jpg`)** + 안전영역 확인용 **가이드본 (`_thumb_instagram_guide.jpg`)** 동시 생성
*   **훅(Hook) 카피라이팅 공식**:
    *   ❌ 긴 설명문 형태 지양 ("나를 지키려던 맹세가 왜 저주가 되었을까?")
    *   ⭕ 2행 호기심/충격/반전형 구조:
        *   1행 (원인/현상): `스스로를 지키려다` / `“너 어차피 안 돼”` / `상처받기 싫어서`
        *   2행 (결과/경고): `괴물이 되는 이유` / `이 말이 아이를 망칩니다` / `마음을 닫은 대가`
*   **포토제닉 프레임 선별**:
    *   3fps 콘택트 시트(Contact Sheet)로 전체 프레임을 덤프하여 입모양이 일그러지지 않고, 활짝 웃는 표정 또는 손동작이 있는 열정적 스피치/포인트 제스처 프레임을 선별.

## 🎥 9:16 크롭 스펙
*   크롭 `1216x2160` → `1080x1920` (lanczos). 세로는 원본 전체 높이를 쓴다.
*   YuNet 으로 10fps 검출 → 컷 경계 인지형 분할 프레이밍.
*   **등속도(Constant Speed) 패닝**: 카메라가 이동할 때 속도가 들쭉날쭉(빠르게/느리게) 변하지 않도록 `PAN_SPEED = 480px/s` 등속 직선 이동(Linear Glide) 적용.
*   **정적 샷 락(Lock)**: 3.5초 미만의 짧은 컷이나 좌우 이동폭이 280px 이내인 제자리 발화는 정적 샷으로 고정. 이전 샷과의 차이가 140px 미만이면 동일 좌표로 락하여 컷 전환 시 불필요한 미세 점프 방지.
*   **비디오 픽셀 컷 스냅 (`snap_cuts_to_visual`) & 0.5프레임 안전 마진**: 무음 제거 후 결합된 비디오의 실제 프레임 픽셀 차이를 탐색하여 컷 경계를 1:1 스냅. FFmpeg `gte()` 시점을 `(cut_frame - 0.5) / FPS` 정중앙으로 설정해 컷 전환 직전 프레임에서 카메라가 먼저 튀는 현상(2단 점프 글리치)을 원천 차단.

## ⚠️ 이 파이프라인에서 실제로 터졌던 것들
1.  **카메라가 사람보다 먼저 움직이거나 속도가 울컥거림 (2026-09-03)** — 가속/감속 스무딩이 오히려 보는 사람에게 멀미를 유발. → 등속도(Constant Speed) 선형 트래킹 + 정적 샷 락으로 안정화.
2.  **효과음이 너무 튀거나 쌩뚱맞음 (2026-09-03)** — 웅장한 북소리나 임팩트 타격음은 설교 영상의 감동을 깸. 이모지 스티커도 조잡함 유발. → 이모지 전면 배제, 45ms 초미세 버블팝 단일 샘플로 통일.
3.  **인스타 업로드 시 썸네일 글자가 잘려나감 (2026-09-03)** — 9:16 유튜브 썸네일을 그대로 올리면 인스타 피드(4:5)와 프로필 그리드(1:1)에서 상단 제목이 통째로 날아감. → 1080x1350 캔버스에 노란 가이드라인(`[161, 164, 921, 1145]`) 안전영역을 정의하고 그 안에 타이포그래피를 완벽 수납한 인스타 전용 커버 생성.
4.  **구간 추출 소리가 33dB 죽음 (2026-09-02)** — 출력쪽 `-ss` 를 쓰면 PTS 가 0 에서 시작하지 않아 `afade=t=out` 이 클립 한가운데서 터진다. → 입력쪽 `-ss` 만 쓰고 `asetpts=PTS-STARTPTS` 를 afade 앞에 건다.
5.  **무음이 하나도 안 잘림 (2026-09-02)** — whisper 토큰 타임스탬프는 앞 토큰 끝 = 뒤 토큰 시작으로 타임라인을 빈틈없이 덮어서, 겹침 기반 단어 가드가 삭제를 전부 취소한다. → 단어 가드는 기본 끔. 무음 판정은 RMS 가 정본, 말끝 보호는 pad(0.12s) 가 한다.
5-1. **★음성도 없는데 컷만 잠깐 바뀌는 구간 (2026-09-03, 오너 지적)** — `pad+pad+keep_gap = 0.42s` 를 빼고 나면 **0.02초만 지우는 삭제 구간**이 남는데, 그래도 화면은 한 번 튄다. 2026-09-02 3편 실측에서 C 안은 컷 14개 중 8개가 0.25초 미만만 지웠고, 조각이 0.70초짜리까지 나왔다. → `silence_cut.py` 에 **`--min-gain 0.40`**(이만큼도 못 지우면 컷 안 함)과 **`--min-keep 1.20`**(컷 사이 조각이 짧으면 덜 지우는 쪽 컷을 취소)을 넣고 잔여 무음을 0.42s→0.30s 로 줄였다. 실측: C 컷 14→5개(길이 53.8→55.1s), B 16→11개(오히려 1.3s 더 줄어듦), A 11→7개. 컷이 말 중간에 떨어진 경우 0건.
6.  **임계값이 너무 보수적 (2026-09-02)** — `floor+8dB` 만 보면 조용한 녹음에서 -47dB 까지 내려간다. → `min(max(floor+6, speech-18), speech-12)`.
7.  **전사문에서 글자가 사라짐 (2026-09-02)** — whisper.cpp 는 한글 한 글자를 토큰 둘로 쪼개 반쪽 UTF-8 을 낸다. `errors="ignore"` 로 열면 그 반쪽이 사라진다("사춘기"→"사기"). → `errors="surrogateescape"` 로 바이트를 보존하고 증분 디코딩한다.
8.  **컷 전환 시 크롭 위치가 1프레임 먼저 튀는 2단 점프 글리치 (2026-09-05, 오너 지적)** — 무음 제거 후 결합된 비디오의 미세 프레임 오차와 FFmpeg `gte(t, cut_time)` 평가 시점으로 인해, 실제 화면이 바뀌기 1프레임 전에 크롭 박스가 먼저 이동하여 [위치만 점프] → [다음 프레임에 화면 전환]의 2단계 글리치가 발생함. → `snap_cuts_to_visual()` 엔진을 탑재해 실제 픽셀 차이 피크 프레임으로 컷 경계를 1:1 스냅하고, FFmpeg `gte()` 시점을 `(cut_frame - 0.5) / FPS` 안전 마진으로 설정하여 화면 전환과 크롭 이동이 단 한 프레임에 100% 동시 전환되도록 일괄 교정.

## 💡 shorts-allinone 과의 관계
*   리졸브에서 손보고 싶다 → `shorts-allinone` (EDL + SRT)
*   그대로 올리고 싶다 → **이 스킬** (완성본 MP4 + 썸네일 2종)
두 스킬 모두 기획 규칙(과소선택 주의, 짜깁기 허용)은 `sermon-shorts-planner` 와 같다.
