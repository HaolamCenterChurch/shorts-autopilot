# ⚠️ shorts-autopilot 과거 디버깅 및 사고 회고록 (Reference)

> **목적**: 과거 회차(2026-09-05 ~ 2026-09-08)에서 실제로 터졌던 버그와 원인 규명 기록.

## ⚠️ 이 파이프라인에서 실제로 터졌던 것 (재발 방지)

**★줌 시각이 옛 편집본 기준으로 남아 있었다 — `_effects.json` 캐시 (2026-09-15 테슈바 32일차)** —
`run_pipeline.py` 가 `_effects.json` 이 **이미 있으면 새로 만들지 않았다.** 무음 설정을 바꿔 Stage A 를
다시 돌리면 타임라인이 달라지는데, 첫 렌더의 줌 시각이 그대로 쓰였다(5편 중 A·B·E 3편).
줌이 강조와 무관한 곳에서 켜졌다가 발화 중간에 빠졌고, A편 "그냥 나를 존재 그 자체 / 부족한 그 자체를"
4초 사이에 줌 켜짐·꺼짐 + 같은 장면 점프컷 + 추적 순간이동(±99px)이 7번 몰려 오너가 **"글리치"** 로 지적했다
(프레임 차이 실측: 41.63 줌꺼짐 13.3 / 41.83 점프컷 15.9 / 44.57 점프컷 15.1 / 45.07 줌 10.9 / 45.57 줌꺼짐 12.1).
→ effects 는 **매 Stage B 마다 새로 만든다.** 줌 규칙은 `zoom_plan.py` 로 옮겼다 —
문장 끝까지 유지 · 그 전에 이음매가 오면 그 컷에서 뺌 · 줌 전환을 이음매 프레임에 맞춰 점프컷을 가림 ·
강조가 이어지면 2단(1.14→1.28). 수동 지정은 `plan.effects.zooms` 에만 둔다(effects.json 손수정은 덮어써진다).

**★인물 추적 크롭이 실제 컷보다 먼저 순간이동했다 — 같은 장면 점프컷 글리치 (2026-09-15 같은 회차)** —
위 A편 글리치의 나머지 절반. 크롭 전 중간본(`master.mov`)으로 재 보니 "부족한 그 자체를" 이음매의 실제 전환은
1343프레임인데 크롭은 **1337프레임에 먼저 96px 이동**했다(6프레임 동안 화면만 옆으로 밀림).
"그냥 나를" 이음매는 원본 변화량이 0.6(자세 그대로)인데도 크롭이 99px 이동했다. C·E편에도 1프레임 어긋남 3곳.
원인 ① `find_shot_boundaries` 가 이음매를 **plan 구간 길이 합산**으로 계산 — 구간마다 인코딩 반올림이 쌓여 4~6프레임 어긋남
② `snap_cuts_to_visual` 탐색 창이 -4~+5프레임뿐이고 변화량 3.5 미만(같은 장면 점프컷)은 못 잡음
③ `static_lock` 60px — 같은 자세에서도 얼굴 검출 흔들림(±99px)이 새 좌표로 채택됨.
→ ① `_raw.mov.segmap.json` 의 실제 이어 붙인 시각 우선 ② 창 ±7프레임 + 창 안 봉우리(중앙값 3배·1.5 이상)면 채택
③ `static_lock` 기본 160px. 점검: `track.json` 의 x 가 20px 이상 바뀌는 프레임이 실제 전환 프레임과 같아야 한다.

**★무음 제거가 작게 말한 말끝을 통째로 잘랐다 — 게이트는 전부 통과 (2026-09-15 같은 회차)** —
G-H(발화 중 무음)를 맞추려 `silence` 를 조이자(min_silence 0.18 / pad 0.07 / keep_gap 0.04 / min_gain 0.02)
작게 끝낸 말(-41~-50dB)이 무음으로 잡혀 8곳이 지워졌다(A "아니라**니까요**"·"사랑하시는 **겁니다**", C "상해야 **됩니다**" 등).
whisper 는 잘린 자리를 비슷한 말("겁니다"→"거예요")로 메워 master 전사가 멀쩡해 보였고 유사도 96~99% 로 통과 —
**잘린 A편이 오너에게 전달됐다.** 삭제 구간 -40dB 진폭 검사로는 못 잡는다.
→ Stage A 뒤 `scripts/shorts_v2/loss_audio_check.py {_work} {slug}` (raw↔master 글자 대조 후보만 두 모델 재전사,
raw 에서 들리고 master 에서 안 들리면 잘림). 잘린 말의 **말소리 구간만** `plan.preserve` 에 넣고 재실행.
⚠ preserve 가 경계 무음까지 덮으면 silence_cut 이 그 삭제 구간을 통째로 취소해 1.4~1.8초 갭이 남는다 — 말끝까지만.
⚠ **segment 경계를 옮겨 생긴 잘림은 이 검사로 못 잡는다**(raw 자체가 이미 잘림). E "없다니까요" 첫소리를 입소리로 오판해
시작을 0.15초 늦췄다가 잘렸다 → 옮긴 경계마다 원본 wav 에서 새·옛 경계로 잘라 두 모델 재전사해 같은지 대조.
- **작은 목소리 구간**: C·D 구간은 발화가 6~8dB 작아 silence_cut 적응 임계가 -46dB 까지 내려가 무음 판정 26%.
  오디오만 증폭·리미터 건 원본 사본(`sermon_4k_gainC.mp4`, 영상 무손실 복사)을 Stage A·B 의 `--src` 로 썼다.
- **G-H 예외**: 작게 말한 보존 말 자체가 -42dB 미만이라 생기는 갭은 내용이 우선 — 보고서에 예외로 적고 오너에게 알린다.
- **whisper 끝 환청**: master 전사 끝에 "감사합니다." "영상편집:서정혁" 이나 앞 문장을 0초 길이로 되풀이한 글자가 붙는다 —
  마지막 청크 끝말 이후를 백업 후 잘라낸다.

**★`preserve` 가 통째로 무시되고 있었다 (2026-09-08 실측, 가장 오래 숨어 있던 버그)** —
`plan.json` 의 `preserve` 는 **원본(src) 절대시간**(예: `[1875.0, 1879.1]`)인데,
`silence_cut.py` 가 보는 것은 세그먼트를 이어붙인 **raw 시간축**(0~85초)이다.
`run_pipeline.py` 가 좌표 변환 없이 그대로 넘기고 있었으므로 **preserve 구간은 항상
범위 밖이었고, 웃음/박수 보존은 한 번도 작동한 적이 없다.** 금기 5번을 지켰다고 믿고
있었지만 실제로는 지켜지지 않았다.
→ `run_pipeline.py` 가 `segments` 로 누적 오프셋을 계산해 src→raw 로 변환한 뒤 넘긴다.
로그에 **`[run_pipeline] preserve src→raw 변환: …`** 이 떠야 작동한 것이다.
⚠ 이 수정으로 **예전 회차를 다시 렌더하면 웃음 구간이 살아나 길이와 결과가 달라진다.**

**★마지막 자막이 영상 끝까지 늘어나 페이드아웃 자리가 없었다 (2026-09-08)** —
`make_ass.py` 가 `ends[-1] = args.duration` 으로 **마지막 블록을 무조건 영상 끝까지** 늘린다.
그래서 `generate_thumbnail.py --ass`(자막이 끝난 뒤 페이드아웃 시작)가 구조적으로 불가능했고
항상 `⚠꼬리 부족` 이 떴다. 실측: 발화는 64.24s 에 끝나는데 자막이 66.30s 까지 떠 있었다.
→ `--last-tail` 옵션 추가(`plan.subs.last_tail`). 마지막 단어 끝 + 이 초에서 자막을 끊는다.
구두점 토큰(`.`, `?`)은 끝 계산에서 제외한다.

**★`last_tail` 이 먹지 않는다 — whisper 가 마지막 단어를 영상 끝 너머까지 늘려 잡는다 (2026-09-08)** —
DTW 가 꼬리 무음을 마지막 단어에 물려 `t1` 이 영상 길이보다 커지면, `last_word_end + last_tail`
이 `duration` 을 넘어 `min()` 에 걸려 **마지막 자막이 결국 영상 끝까지 늘어난다.**
실측 B안: 마지막 단어 `요` 의 `t1 = 80.40` 인데 영상은 `80.233` — 실제 발화는 `79.25` 에 끝났다.
→ `make_ass.py` 가 **`t1 > duration` 인 토큰은 건너뛰고** 그 앞 토큰을 기준으로 삼도록 고쳤다.
A안처럼 타임스탬프가 정상인 경우에는 결과가 바뀌지 않는다.

**★preserve 를 넉넉히 잡으면 무음이 폭증한다 (2026-09-08)** —
좌표 변환 버그가 고쳐지기 전에는 preserve 가 무시됐으므로 구간을 아무렇게나 넓게 잡아 두었다.
변환이 작동하기 시작하자 그 안의 **정적까지 통째로 보존**되어 무음이 튀었다.
실측 B안: `[3057.52, 3071.76]`(14.24초) 안에 실제 웃음은 `3060.5~3062.9`(2.4초)뿐이고
나머지는 −55~−64dB 정적이었다. 무음 11.2% → 실제 웃음만 남기니 6.4% → 정적 컷까지 하니 2.6%.
→ **옛 회차 plan 을 다시 돌릴 때는 preserve 를 반드시 다시 재서 좁힌다.**

**★말더듬·반복 발화는 무음 제거기가 못 잡는다 (2026-09-08, 오너 지적 3건)** —
"결혼식 때 … 결혼식 때" 같은 반복과 "어/으/그" 간투사는 **소리가 있으므로**
`silence_cut.py` 대상이 아니다. 실측: 완성본 8.32~10.00s 에 반복이 그대로 남았고,
그 사이 0.66초 멈칫 동안 **다음 자막이 먼저 떠 있었다.**
→ Phase 2 의 역매핑 절차로 원본 좌표를 찾아 `segments` 를 쪼갠다.
⚠ **간투사는 겹쳐서 두 개씩 있다.** "어"만 자르면 "그"가 남는다 — 자른 뒤 반드시 재전사한다.
⚠ 짧은 조각을 whisper 에 물리면 "시청해주셔서 감사합니다" 같은 **환각 문장**이 나온다.
이것은 **소리가 없다는 뜻이 아니라 글자로 옮길 게 없다는 뜻**이다. 파형(RMS)으로 판단하라.

**★재렌더가 통째로 버려진다 (2026-09-06 실측)** — `generate_thumbnail.py --video` 는
`_work/{slug}_raw.mp4` 백업이 **이미 있으면 그 백업을 소스로 삼는다**(백업 확인 함수 동작).
자막을 고쳐 stage b 를 다시 돌려도, 지난 회차의 `_raw.mp4` 가 남아 있으면 **새 렌더가
버려지고 옛 영상에 인트로만 새로 붙는다.** 더 나쁜 건 `.ass`·`words.json` 기반 검증은
전부 통과한다는 것이다(실측: 자막 텍스트가 옛것인데 `check_chunks` ✅, 유사도 96.80%).

→ **재렌더할 때는 `_work/{slug}_raw.mp4` 를 먼저 지운다.** 그리고 Gate 8 의
**G-F(MP4-ASS 길이차)** 로 묵은 렌더를 잡는다. 실측: C안 mp4 61.62s vs ASS 끝 56.93s
→ 길이차 +4.68s 로 즉시 검출(`--no-intro` 표준에서 정상은 **+0.4s 안팎**, 실측 A안 +0.41s).

**★컷이 바뀌면 인물이 화면 밖에서 시작해 패닝으로 찾아간다 (2026-09-06, 오너 지적)** —
`track_crop.py` 가 `moving_median`(`med_window = 1.5 × sample_fps`, 즉 **±0.7초**)과
`np.interp` 를 **전체 타임라인에 한 번에** 걸고 있었다. 그래서 컷 경계에서 얼굴 위치가
불연속으로 튀면 스무딩이 경계를 넘나들며 섞이고, 새 샷의 첫 프레임 얼굴 좌표가
**이전 샷 쪽으로 끌려간 중간값**이 된다. 이동 샷의 시작 카메라는 `clip_cx[0]` 로 잡으므로
카메라가 엉뚱한 곳에서 출발해 인물을 향해 패닝한다.
실측(C안): 세그먼트 이음새 4.43s 에서 인물은 `x=1762` 인데 카메라가 `x=985` 에서 시작해
**6.97s 까지 2.5초를 패닝**했다. 컷 직후 프레임에서 설교자가 오른쪽 끝에 잘려 있었다.
→ **컷 경계를 먼저 구하고, 스무딩과 보간을 샷 안에서만 한다.** `find_shot_boundaries()` 를
`moving_median` 앞으로 옮기고 샷별로 잘라 돌린다(`np.interp` 는 범위 밖을 끝값으로 고정하므로
샷을 넘어 섞이지 않는다). 실측: 컷 직후 `x=985 → 1750` 즉시 스냅, 인물이 정중앙.
⚠ 이 수정으로 **G-D 카메라 이동 비율이 오히려 내려간다**(C안 16% → 11%). 헛패닝이
사라진 것이므로 정상이다 — G-D 가 낮다고 되돌리지 마라.

**★자막이 1080px 화면 밖으로 넘치고 잘림 (2026-09-13, 오너 지적)** —
과거 68pt 기준일 때 쓰던 '1줄 15자 한계'가 90pt 대형 자막으로 승격된 뒤에도 검증기에서 방치되어 있었다.
90pt 어그로/산돌고딕 폰트는 1자당 ~78px, 띄어쓰기 ~25px를 차지하여 12자(934px)를 넘으면 13자부터 1012px로 1080px 안전 마진을 뚫고 잘린다.
`check_chunks.py`가 단순 18자 초과만 ⚠️ 경고하고 통과시켰기 때문에 14~20자(최대 1340px) 블록 14개가 그대로 렌더되어 화면 좌우 밖으로 삐져나갔다.
→ 1) `check_chunks.py`에 PIL ImageFont 실측 너비 계산을 도입하여 960px 초과 또는 1줄 12자 초과 시 하드 에러(`exit 1`)로 빌드를 즉시 차단.
2) `make_ass.py`에 자동 2행 분할(`\N`) 및 폰트 피팅 스케일 다운 로직을 안전망으로 내장.
3) `check_output.py`에 Gate G-G(자막 레이아웃 한계 <= 980px)를 신설하여 최종 MP4 검증 단계에서 사후 차단.
4) 긴 문장은 1줄 7~10자 호흡 단위로 분할하거나 `\N`으로 2행 처리.

**★말더듬·반복 발화가 컷팅 없이 방치됨 (2026-09-13, 오너 지적)** —
오너가 "말을 쓸데없이 반복하는 것 더듬는 것도 다 자르기로 했는데? 스킬에 안 적혀있나?"라고 강력 지적.
`silence_cut.py`는 무음만 자르므로, 유음 중복("우리가 우리가", "넷플릭스보다 성경이 더 재밌다" 2회 반복, "드라마 볼 시간인데 성경 읽고 이거 너무 너무 있어요" 재시작)은 잡지 못한다.
에이전트가 Phase 2의 ② 전사 통독 및 `cut_fillers.py` 절차를 '오너가 명시적으로 요구할 때만 하는 옵션'으로 오인하여 생략했던 것이 원인.
→ 10대 금기 사항 10번에 명시하고, Phase 2에서 전사 통독 및 반복/말더듬 컷팅을 **선택이 아닌 상시 필수 공정**으로 강제.
